# ❌ No-as-a-Service

Ever needed a graceful way to say “no”?
This tiny mini-app returns random, generic, creative, and sometimes hilarious rejection reasons — perfectly suited for any scenario: personal, professional, student life, dev life, or just because.

Built for humans, excuses, and humor.
